## 개요

QuantInvest Tool GUI는 전문적 와이어프레임, 상세한 컴포넌트 사양, 색상 구성, 타이포그래피 가이드라인, 구체적인 구현 예제로 포괄적으로 설계되었습니다. 이 설계는 프로덕션 준비 완료 상태이며 개발자가 직접 구현할 수 있습니다.

## 완전한 설계 사양

### 탭 1: 주식 설정

**목적**: 주식 데이터 다운로드 및 관리

**컴포넌트**:
- 주식 티커 입력 필드
- 날짜 범위 선택기 (캘린더 팝업 포함)
- 캐시 선호도 체크박스
- "데이터 다운로드" 버튼
- "캐시 삭제" 버튼
- 다운로드 중 진행률 바
- 데이터 미리보기 패널
- 상태 메시지

**기능**:
- 입력 검증 (티커 형식, 날짜 범위)
- 백그라운드 다운로드 워커 (비차단)
- 다운로드 전 캐시 확인
- Yahoo Finance 통합
- SQLite 캐시 관리
- 실시간 진행률 피드백
- 사용자 메시지가 포함된 에러 처리

---

### 탭 2: 전략 선택 & 파라미터

**목적**: 거래 전략 구성 및 파라미터 설정

**컴포넌트**:
- 전략 드롭다운 (4개 옵션)
- 전략 설명 레이블
- 동적 파라미터 입력 필드

**전략 파라미터**:
```
모멘텀:
  - momentum_period: 3-30 (정수)
  - mfi_level: 20-80 (부동수, %)
  - stop_loss: 1%-20% (부동수, %)

추세 추종:
  - short_window: 5-30 (정수)
  - long_window: 20-100 (정수)
  - stop_loss: 1%-20% (부동수, %)

평균 회귀:
  - lookback_period: 5-50 (정수)
  - z_score: 0.5-3.0 (부동수)
  - position_size: 1%-100% (부동수)

포트폴리오:
  - portfolio_size: 2-10 (정수)
  - correlation_filter: 0.0-1.0 (부동수)
  - weight_method: 동일/시가총액/역분산 (선택)
```

---

### 탭 3: 최적화 설정

**목적**: 전략의 최적 파라미터 검색 범위 구성

**컴포넌트**:
- "파라미터 최적화 활성화" 체크박스
- 파라미터 범위 입력 (최소, 최대, 단계)
- 조합 수 계산기 (실시간)
- 시간 추정 (과거 성능 기반)
- "병렬 처리" 체크박스
- 스레드 수 선택기
- 선택적 제약 조건 입력
- "최적화 시작" 버튼

**작업 흐름**:
1. 사용자가 최적화 활성화
2. 파라미터 범위가 기본값으로 자동 채워짐
3. 사용자가 범위 조정
4. 시스템이 조합 수 & 시간 추정 계산
5. 사용자가 선택적 제약 조건 설정
6. "최적화 시작" 클릭
7. 백그라운드 워커가 그리드 검색 실행
8. 실시간 진행률로 최선 파라미터 표시
9. 완료 시 탭 4로 자동 전환

---

### 탭 4: 결과 & 분석

**목적**: 백테스트 결과 표시 및 분석

**컴포넌트**:
- 지표 표 (2열)
- "지표 복사" 버튼
- 차트 탭 (4개 차트 유형)
- 내보내기 버튼
  - "CSV 내보내기"
  - "차트 내보내기"
  - "PDF 보고서 생성"

**표시 지표**:
```
전략 지표:
├─ CAGR (%)
├─ 샤프 지수
├─ 최대 낙폭 (%)
├─ 승률 (%)
├─ 수익/손실 비율
└─ 칼마 비율 (선택)

거래 분석:
├─ 총 거래 수
├─ 수익 거래
├─ 손실 거래
├─ 평균 수익 거래 (%)
├─ 평균 손실 거래 (%)
└─ 평균 보유 기간 (일)

비교:
├─ 전략 vs 매수&보유 CAGR
├─ 전략 vs 매수&보유 샤프 지수
└─ 전략 vs 매수&보유 MDD
```

## 상호작용 흐름

### 흐름 1: 기본 백테스트 (사용자가 주식 선택, 전략 선택, 백테스트 실행)

```
탭 0: 주식 설정
    ↓ [데이터 다운로드]
    ↓ (1-30초 다운로드)
    ↓ [데이터 준비 신호]
탭 1: 전략 선택 (활성화)
    ↓ [전략 & 파라미터 선택]
    ↓ [검증]
탭 2: 최적화 (활성화)
    ↓ [최적화 스킵]
    ↓ [백테스트 실행]
    ↓ (1-2초 백테스트)
탭 3: 결과 (자동 전환)
    ↓ [지표 & 차트 표시]
    ↓ [필요시 내보내기]
```

**소요 시간**: 5-10분 (대부분 다운로드 시간)

### 흐름 2: 완전 최적화 (파라미터 범위를 통한 그리드 검색)

```
탭 2: 최적화 (활성화)
    ↓ [파라미터 범위 설정]
    ↓ [520개 조합 계산]
    ↓ [최적화 시작]
    ↓ (10-30분 진행률 포함)
    ├─ 실시간: "235/520 - 최선: 467%"
    ├─ 진행률: 47%
    └─ 차트 실시간 업데이트
    ↓ [완료]
탭 3: 결과 (자동 전환)
    ↓ [최적 파라미터 표시]
    ↓ [최선 지표 표시]
```

**소요 시간**: 15-45분 (범위에 따라 다름)
