# QuantInvest Tool - UI 디자인 시스템

## 설계 시스템 개요

QuantInvest Tool을 위한 전문적이고 일관성 있는 디자인 시스템으로, 모든 탭과 대화상자에서 시각적 일관성, 접근성, 사용성을 보장합니다.

## 반응형 설계

### 중단점
```
작음:    < 600px   (매우 작은 창, 모바일 형태)
중간:    600-1024px (랩탑/데스크톱 표준)
큼:      > 1024px  (넓은 데스크톱)
```

### 반응형 동작

**작은 화면 (< 600px)**
- 탭을 가로 → 세로 스크롤 가능하게 스택
- 패딩을 12px로 줄임
- 지표 표는 가로 스크롤 가능
- 차트 너비에 맞게 스케일
- 버튼: 전체 너비

**중간 화면 (600-1024px)**
- 표준 레이아웃
- 해당하는 곳에 두 열
- 정상 패딩

**큰 화면 (> 1024px)**
- 다중 열 레이아웃
- 확대된 간격
- 더 크고 넓은 차트 및 표

### 최소 실행 가능 창 크기
- 너비: 800px (하드 최소)
- 높이: 600px (하드 최소)
- 최소 이하: 스크롤 바 표시, 일부 기능 비활성화

## 접근성 (A11y)

### 키보드 네비게이션

**탭 순서**
1. 메뉴 바
2. 도구 모음 (있는 경우)
3. 탭 위젯 (왼쪽에서 오른쪽)
4. 탭 콘텐츠 (위에서 아래)
5. 상태 표시줄

**키보드 단축키**
```
Ctrl+Q             종료
Ctrl+S             세션 저장
Ctrl+O             세션 열기
Ctrl+E             결과 내보내기
Ctrl+R             백테스트 실행
Ctrl+F             찾기
Alt+H              도움말
Tab                앞으로 탐색
Shift+Tab           뒤로 탐색
Enter              버튼/입력 활성화
Space              체크박스/버튼 토글
화살표 키           스크롤/스피너 변경
```

### 화면 읽기 지원
- 모든 버튼에 설명적 레이블 있음
- 입력 필드에 연결된 레이블 있음
- 이미지에 대체 텍스트 있음
- 표에 헤더 행 표시됨
- 에러 메시지 발표됨

### 색 대비
- 텍스트: 최소 4.5:1 명암비 (WCAG AA)
- 비활성 요소: 최소 3:1 대비
- UI 컴포넌트: 최소 3:1 명암비

### 포커스 표시기
```
포커스 윤곽선: 2px solid #0D47A1
오프셋: 요소에서 2px
```

## 애니메이션 & 전환

### 탭 전환
- 지속 시간: 200ms (페이드)
- 이징: Ease-in-out

### 버튼 상호작용
- 호버: 100ms 색 전환
- 클릭: 즉시
- 해제: 100ms 색 전환

### 진행률 업데이트
- 선형 진행률 바 애니메이션
- 부드러운 값 업데이트 (점프 없음)
- 백분위 텍스트 업데이트: 정수 반올림

### 차트 렌더링
- 초기 로드: 500ms 페이드인
- 데이터 업데이트: 300ms 애니메이션 (선 이동)

## 성능 최적화

### 지연 로딩
- 선택한 탭일 때만 차트 렌더링
- 큰 표는 페이지당 20행으로 페이지 분할
- 변경되지 않은 요소 다시 그리기 최소화

### 렌더링
- Qt의 이중 버퍼링 사용
- 변경되지 않은 요소의 다시 그리기 최소화
- 복잡한 차트에는 QGraphicsView 사용

### 메모리
- 차트 히스토리를 500포인트로 제한 (필요시 다운샘플)
- 완료 후 워커 스레드 신호 삭제
- 캐시 행렬 계산
